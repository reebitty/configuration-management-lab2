# Визуализатор графа зависимостей пакетов NuGet (Вариант 23)

## 1. Общее описание
Консольное (CLI) приложение для построения и визуализации графа зависимостей пакетов менеджера пакетов .NET (NuGet). Готовые менеджеры пакетов и библиотеки для получения зависимостей не используются.

Проект написан на языке Python 3.12 с использованием только стандартной библиотеки в рамках практической работы по дисциплине «Конфигурационное управление».

**Этап 1 (текущий).** Минимальный прототип с конфигурацией: приложение принимает параметры из командной строки, проверяет их и выводит все параметры в формате ключ-значение.

## 2. Описание всех функций и настроек

### Параметры командной строки

| Параметр | Ключ в выводе | Описание | По умолчанию |
|---|---|---|---|
| `-p`, `--package <имя>` | `package` | Имя анализируемого пакета. | обязательный |
| `-r`, `--repo <url или путь>` | `repo` | URL-адрес репозитория или путь к файлу тестового репозитория. | обязательный |
| `-t`, `--test-mode` | `test_mode` | Режим работы с тестовым репозиторием: в `--repo` указывается путь к файлу. | выключен |
| `-o`, `--output <файл>` | `output` | Имя сгенерированного файла с изображением графа (`.svg`). | `graph.svg` |
| `-a`, `--ascii-tree` | `ascii_tree` | Режим вывода зависимостей в формате ASCII-дерева. | выключен |
| `-d`, `--max-depth <число>` | `max_depth` | Максимальная глубина анализа зависимостей. | `3` |
| `-h`, `--help` | — | Справка по параметрам. | — |

При успешном запуске приложение выводит все параметры в формате ключ-значение и завершается с кодом `0`.

### Обработка ошибок
Все параметры проверяются перед запуском. Если найдены ошибки, выводятся **все** ошибки (по одной на строку, с префиксом `Ошибка:` и именем параметра), а приложение завершается с кодом `1`.

| Параметр | Ошибки |
|---|---|
| `--package` | имя не задано; длиннее 100 символов; содержит символы, кроме латинских букв, цифр и `.` `_` `-` |
| `--repo` | не задан; без `--test-mode` — не является URL-адресом с `http://` или `https://`; с `--test-mode` — файл не найден |
| `--output` | пустое имя файла; недопустимые символы `<>:"\|?*`; расширение не `.svg`; указанная папка не существует |
| `--max-depth` | не целое число; меньше `1` |

### Функции
* `parse_args()` — разбор параметров командной строки (`argparse`).
* `validate_package()`, `validate_repo()`, `validate_output()`, `validate_max_depth()` — проверка отдельных параметров, возвращают текст ошибки или `None`.
* `validate_args()` — проверка всех параметров, возвращает список ошибок.
* `make_config()` — сборка параметров в словарь ключ-значение.
* `print_config()` — вывод параметров.
* `main()` — точка входа, возвращает код завершения.

### Тестовый репозиторий
Файл `repos/test_repo.txt` — пример файла тестового репозитория для режима `--test-mode`. Пакеты в нем называются большими латинскими буквами.

## 3. Описание команд для сборки проекта и запуска тестов

### Сборка и зависимости
Используется только стандартная библиотека Python, установка сторонних пакетов не требуется. Для изоляции можно создать виртуальное окружение:
```bash
python -m venv .venv
```

### Запуск
```bash
python src/main.py --package Newtonsoft.Json --repo https://api.nuget.org/v3/index.json
```

Скрипты для Windows в папке `scripts/` (запускаются из корня проекта):
* `scripts\run.bat` — запуск с URL-адресом репозитория и всеми параметрами;
* `scripts\run_test_mode.bat` — запуск в режиме тестового репозитория (короткие ключи и значения по умолчанию);
* `scripts\run_errors.bat` — демонстрация обработки ошибок для всех параметров.

### Запуск тестов
```bash
python -m unittest discover -s tests
```

## 4. Примеры использования

### Все параметры
```text
> python src/main.py --package Newtonsoft.Json --repo https://api.nuget.org/v3/index.json --output graph.svg --ascii-tree --max-depth 2
Параметры запуска:
package: Newtonsoft.Json
repo: https://api.nuget.org/v3/index.json
test_mode: False
output: graph.svg
ascii_tree: True
max_depth: 2
```

### Режим тестового репозитория и значения по умолчанию
```text
> python src/main.py -p A -r repos/test_repo.txt -t
Параметры запуска:
package: A
repo: repos/test_repo.txt
test_mode: True
output: graph.svg
ascii_tree: False
max_depth: 3
```

### Обработка ошибок
```text
> python src/main.py
Ошибка: не задано имя пакета (--package)
Ошибка: не задан URL-адрес или путь к репозиторию (--repo)

> python src/main.py --package "bad name!" --repo nuget --output graph.png --max-depth -5
Ошибка: недопустимое имя пакета 'bad name!': разрешены латинские буквы, цифры и символы . _ - (--package)
Ошибка: некорректный URL-адрес репозитория 'nuget': ожидается адрес вида https://... (для файла укажите --test-mode)
Ошибка: файл с изображением графа должен иметь расширение .svg: 'graph.png' (--output)
Ошибка: максимальная глубина должна быть не меньше 1, получено -5 (--max-depth)

> python src/main.py -p A -r missing_repo.txt -t
Ошибка: файл тестового репозитория 'missing_repo.txt' не найден (--repo)
```
